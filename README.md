# 🍳 Recipe Finder App

A dynamic **Recipe Finder** web application built using **HTML, CSS, and JavaScript**.  
This app integrates with a recipe API to help users search, explore, and view cooking instructions for various dishes.

---

## 🚀 Features

- 🔍 **Search Recipes**  
  Enter keywords (e.g., "pasta", "chicken") to find matching recipes.

- 📸 **Recipe Details**  
  View ingredients, instructions, and images for each recipe.

- 📱 **Responsive Design**  
  Works seamlessly across desktop, tablet, and mobile devices.

- 🌐 **API Integration**  
  Fetches real-time recipe data from a public API.

- ✨ **Smooth UI/UX**  
  Clean layout with interactive elements and transitions.
